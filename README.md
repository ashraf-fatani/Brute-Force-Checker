# Brute Force Password Checker

A simple project made with C++ that analyzes the complexity and the efficiency of password against the Brute Force.

The code will analyze:
- The length
- The number of uppercase and lowercase letters
- Numbers
- Special symbols (e.g. !, @, #, etc)
- Count the brute-force attempts

## How to use
- Open the file above, copy it and paste it on your VScode and make sure that you've installed C/C++ compiler
- After paste it on VScode run it
- Enter a password
- The code will classify your password as:
  Very Easy
  Easy
  Medium
  Hard
  Very Hard
